# BK46 固件说明（RMK / ZMK 移植要点）

硬件为 nRF52840（Raytac MDBT50Q-1MV2）。可刷 RMK（配 Vial 上位机）或 ZMK；QMK / Vial-QMK 不支持这颗芯片。
下面三块功能在 RMK、ZMK 里都没有现成实现，需要作为自定义模块开发。引脚见 `pcb/main/keymap.json`。

## 1. 按键扫描（磁轴 + 机械轴 + 旋钮下压，同一条链路）

- 3 颗 CD74HC4067，选择线 S0–S3 共用，输出 MUXA / MUXB / MUXC 接 SAADC。参考电压用 VDD/4 配 1/4 增益，结果与电源成比例。
- 传感器经 10 kΩ 输出，采样保持时间取 10 µs 以上，切通道后等 5 µs 再采。
- 扫一遍 16 个通道 × 3 路并行，约 0.3 ms；1 kHz 扫描足够。
- `SENSE_EN`（P1.12，低有效）控制传感器电源。活动时常开；空闲 3 秒后改为每秒 16 次、每次上电约 0.3 ms 的低频扫描；传感器上电后先等其稳定（按所选型号手册，典型 50–100 µs）。
- 每键校准时判定类型并存入闪存：
  - 读数能被拉到接近 0（< 约 50 mV）→ 机械轴，按数字开关处理，带消抖。
  - 否则 → 磁轴，记录释放值和触底值，按查表线性化，支持可调触发点和快速触发。
- 复用器 A、C 各有一路接旋钮下压传感器（`PRESS1`、`PRESS2`），和磁轴同样读法，见第 3 节。
- 每键的 `mux`、`channel`、`led` 序号在 `keymap.json` 的 `keys` 数组里。

## 2. 旋钮力反馈

硬件：1404 级无刷电机（12N14P，7 对极）+ STSPIN233 + MT6701（SSI，14 位）。

- 三相 PWM：左旋钮 P1.10 / P1.11 / P1.13，右旋钮 P0.13 / P0.15 / P0.17。用 nRF 的 PWM 外设中心对齐模式，25–40 kHz。STSPIN233 内部自带死区，每相只需一路 PWM。
- 编码器：CLK P0.22、DO P0.24 共用，CSN1 P1.15、CSN2 P0.20 分别片选。SPI 模式 1，1–2 MHz，读 24 位取高 14 位。
- 驱动使能固定跟随旋钮电源；`KNOB_PWR_EN`（P0.19，低有效）整路断电时驱动进入待机（约 80 nA），编码器也断电。
- 控制方式：电压模式磁场定向控制，1 kHz 环路即可。电机相电阻很低（约 0.2–0.4 Ω），**必须限制占空比**，建议把等效相电流限制在 1.2 A 以内（约对应占空比 10% 量级，按实测电阻标定）。
- 上电先做电角度对齐（通一个固定矢量，读编码器，记下零偏）。

力反馈效果都是「位置 → 力矩」的函数，建议做成可配置的效果表：

| 效果 | 做法 |
|---|---|
| 段落（刻度） | 力矩 = −K·(角度 − 最近刻度)，刻度数可设；经过刻度时发一次编码器事件 |
| 细 / 粗刻度切换 | 同上，改刻度间距和 K |
| 端点限位 | 超出范围后加大弹簧刚度，并叠加一个短促反向脉冲 |
| 回中弹簧 | 力矩 = −K·(角度 − 中点)，松手自动回中，用于模拟摇杆轴、音量微调 |
| 阻尼 | 力矩 = −B·角速度，手感变"稠" |
| 自由滚动 | 力矩 = 0，电机断电，功耗为零 |
| 多挡开关 | 少量大间距、大刚度的刻度 |
| 按键咔哒 | 检测到下压过阈值时，输出一次 3–5 ms 的双向力矩脉冲 |
| 震动提示 | 叠加 150–250 Hz 的交变力矩，幅度和时长可设（如层切换、电量低、宏录制开始） |

低功耗要点：

- 只有偏离刻度中心或正在转动时才输出力矩；静止在刻度中心时占空比为 0。
- 500 ms 无转动后关闭 PWM，只保留编码器低频轮询（如 50 Hz）；3 秒无操作整路断电，由按键或下压唤醒后重新上电。
- 无线模式下可把力矩上限减半。

## 3. 旋钮下压识别

- 电机座是一块由 4 根 FR4 梁悬挂的小岛，按压时下沉几十微米。小板背面轴心处的 Z 向线性磁传感器对着底壳上的 Ø3×0.5 磁铁，位移变成电压。
- 读数走复用器通道（左：复用器 A 通道 0；右：复用器 C 通道 15），与磁轴同一套采样。
- 用"基线跟踪 + 相对阈值"判断：基线用慢速低通（时间常数约 2 s，仅在未按下时更新），读数偏离基线超过阈值即为按下，回落到阈值的 60% 以下为松开。
- 阈值、长按时间、力度分级（轻按 / 重按）都做成可配置。
- 电机输出大力矩的瞬间会有少量串扰，按下判定可在力矩脉冲期间屏蔽几毫秒。
- 旋钮电源关闭时下压传感器也断电；需要"按旋钮唤醒"的话，空闲时让 `KNOB_PWR_EN` 跟随传感器的低频扫描一起短暂上电即可（MT6701 约 10 mA，占空比很低）。

## 4. 其余外设

| 外设 | 接口 | 备注 |
|---|---|---|
| RGB | P0.23 数据，P1.14 电源使能（高有效） | 46 颗 WS2812B-2020，顺序见 `keymap.json` 的 `led`；固件限制总电流（USB 约 400 mA，电池约 150 mA），熄灯后关电源 |
| OLED | I2C：SDA P0.14，SCL P0.16 | SSD1306 128×32，地址 0x3C；模块自带上拉 |
| 电池电压 | P0.04 | 1:1 分压（2 × 1 MΩ） |
| 充电状态 | P0.03 | BQ24075 的 CHG 脚，开漏低有效，开内部上拉 |
| 外置闪存 | SPI：CS P0.02，CLK P0.28，MOSI P0.26，MISO P0.05 | W25Q32，可选；层和宏放主控内部闪存已足够 |
| 2.4G | — | 用 nRF52840 USB 接收器配对；RMK / ZMK 的分体或接收器方案均可参考 |

左旋钮的三相 PWM 和片选落在 P1.10–P1.15 上，这几个脚在芯片手册里属于"低频引脚"（靠近射频部分）。这样分配是为了让左右旋钮信号分别从模块两侧出线；代价是左旋钮出力时蓝牙灵敏度可能略降，需实测，必要时把 PWM 频率降到 20 kHz 左右。
